## 🏆 Core Technologies

These projects provide important functionality used by Seal Plus.

| Project | Description | License |
|---------|-------------|---------|
| **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** | Powerful command-line media downloader supporting a large number of websites | Unlicense |
| **[youtubedl-android](https://github.com/yausername/youtubedl-android)** | Android wrapper and integration for yt-dlp | GPL-3.0 |
| **[aria2](https://github.com/aria2/aria2)** | High-speed download utility | GPL-2.0 |
| **[Mutagen](https://github.com/quodlibet/mutagen)** | Python library for reading and writing audio metadata | GPL-2.0 |

These projects provide functionality that would otherwise require significant development effort to implement from scratch.

## 📦 Libraries & Dependencies

Seal Plus also relies on a number of open-source libraries from the Android ecosystem.

### Android & Kotlin

- **[Kotlin](https://kotlinlang.org/)** — The primary programming language used by Seal Plus.
- **[Jetpack Compose](https://developer.android.com/jetpack/compose)** — Declarative UI toolkit used to build the application interface.
- **[Android Jetpack](https://developer.android.com/jetpack)** — Android libraries that provide components and APIs used throughout the application.

### Networking & Data

- **[OkHttp](https://github.com/square/okhttp)** — HTTP client used for networking.
- **[Room](https://developer.android.com/training/data-storage/room)** — Persistence library used for local data storage.
- **[Kotlin Coroutines](https://github.com/Kotlin/kotlinx.coroutines)** — Used for asynchronous and concurrent operations.
- **[Koin](https://insert-koin.io/)** — Dependency injection framework used by the application.
- **[Coil](https://github.com/coil-kt/coil)** — Image loading library for Android.

Please see the project's Gradle configuration for the complete and most up-to-date list of dependencies.

## 🌑 Gradient Dark Theme

Seal Plus includes its own **Gradient Dark Theme**, which introduces an alternative visual style with gradient-based backgrounds and glass-like UI elements.

The feature was designed and implemented by **[Mahesh Technicals](https://github.com/MaheshTechnicals)**.

Related resources:

- [Gradient Dark Theme Implementation Guide](https://github.com/MaheshTechnicals/Sealplus/blob/main/GRADIENT_DARK_IMPLEMENTATION_GUIDE.md)

The implementation includes custom resources, components, theming, and supporting documentation developed specifically for Seal Plus.
