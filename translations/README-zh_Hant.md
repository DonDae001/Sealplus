## ✨ 主要功能

### 🎨 高級 UI 與主題
- **漸層深色主題**
  - ⭐ *Seal Plus 獨家功能* — OLED 友善的深色背景、鮮豔漸層、玻璃擬態效果以及流暢動畫。
- **Material Design 3** — 動態色彩、深色/淺色主題以及現代化 Compose 元件。

### 🎯 核心下載功能
- **通用下載器** — 透過 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 支援 1000+ 個平台。
- **高品質音訊擷取** — 擷取 MP3、M4A、OPUS、FLAC 或 WAV，並透過 [mutagen](https://github.com/quodlibet/mutagen) 嵌入中繼資料與縮圖。
- **播放清單支援** — 下載完整播放清單，支援進度追蹤、自訂命名與續傳功能。
- **字幕支援** — 將字幕嵌入影片，或單獨下載字幕，並支援多種語言。

### ⚡ 進階功能
- **高速下載** — 內建 [aria2c](https://github.com/aria2/aria2) 引擎，支援多連線下載、自動重試與續傳。
- **自訂指令** — 建立並儲存自訂 yt-dlp 指令範本，支援完整 CLI 功能。
- **下載管理器** — 追蹤下載歷史、搜尋與篩選下載內容、分享檔案以及執行批次操作。

### 🚀 Seal Plus 獨家功能
- **自動更新系統** — 自動檢查版本、顯示更新日誌，並支援一鍵更新 APK。
- **強化社群** — 存取 [YouTube 教學](https://youtube.com/@maheshtechnicals) 與 [Telegram 社群](https://t.me/maheshtechnicals)，取得定期更新與支援。

### 💻 技術優勢
- **純 Kotlin 架構** — 單一 Activity、100% Jetpack Compose UI、Clean MVVM 以及 Kotlin Coroutines。
- **現代技術堆疊** — Android SDK 37、Kotlin 2.3.21、Jetpack Compose BOM 2026.05.01、Room 2.8.4 以及 Material 3。
- **效能最佳化** — 硬體加速動畫、高效記憶體管理，以及注重電池續航的背景處理。

## ⬇️ 下載與安裝
<div align="center">
<img src="https://github.com/nyxiereal/get-it-on/blob/master/badges/png/github.png" width=258 height=100>

<i>對於大多數 Android 裝置，建議安裝 **arm64-v8a** 版本以獲得最佳效能。</i>

### 📱 裝置相容性

| 要求 | 規格 |
|------------|---------------|
| **最低 Android 版本** | Android 7.0 (API 24) |
| **目標 Android 版本** | Android 17 (API 37) |
| **目前版本** | 3.0.0 |
| **發布日期** | 2026 年 7 月 30 日 |

### 📋 安裝說明

1. 從 [Releases](https://github.com/MaheshTechnicals/Sealplus/releases/latest) 下載適合裝置架構的 APK
2. 在設定 → 安全性中啟用「允許從未知來源安裝」
3. 開啟下載的 APK 檔案
4. 按照安裝提示操作
5. 啟動應用程式時授予必要的權限
6. **享受**流暢的下載體驗！

> [!TIP]
> **自動更新功能**：安裝後，Seal Plus 會自動檢查更新。有新版本時，你會收到通知，並可以一鍵完成更新！

> [!WARNING]
> **安全提醒**：請始終僅從我們的[官方 GitHub Releases 頁面](https://github.com/MaheshTechnicals/Sealplus/releases)下載 Seal Plus。請勿從第三方來源下載，以確保取得正版且安全的版本。

## ❓ 常見問題

<details>
<summary><b>📱 如何啟用漸層深色主題？</b></summary>

1. 開啟**設定**
2. 前往**外觀與體驗**
3. 啟用**深色主題**（如果尚未開啟）
4. 開啟 **Gradient Dark** 開關
5. 享受高級玻璃擬態 UI！

此主題採用深色背景，搭配鮮豔的藍紫色漸層與流暢動畫。
</details>

<details>
<summary><b>🔄 自動更新如何運作？</b></summary>

Seal Plus 會自動從 GitHub Releases 檢查更新：
- 所有安裝預設啟用
- 開啟應用程式時檢查（不會造成打擾）
- 更新前顯示更新日誌
- 一鍵下載並安裝
- 可在設定 → 關於 → 自動更新中停用

不再需要手動檢查更新！
</details>

<details>
<summary><b>📥 我應該下載哪個架構？</b></summary>

| 架構 | 建議使用對象 |
|--------------|-----------------|
| **arm64-v8a** | 大多數現代 Android 手機（2017 年以上）— **推薦** |
| **armeabi-v7a** | 較舊的手機（2011–2017 年） |
| **x86_64** | Intel/AMD 裝置、模擬器 |
| **x86** | 較舊的 Intel/AMD 裝置 |
| **universal** | 適用於所有裝置（檔案較大） |

本專案已透過 BrowserStack 進行測試。

**不知道該選哪個？** 下載 **universal** APK — 它適用於所有裝置！
</details>

<details>
<summary><b>🌍 可以使用它從任何網站下載嗎？</b></summary>

Seal Plus 透過 yt-dlp 支援 **1000+ 個平台**，包括：
- ✅ YouTube、YouTube Music
- ✅ Instagram、TikTok、Twitter/X
- ✅ Facebook、Reddit、Vimeo
- ✅ Twitch、SoundCloud、Bandcamp
- ✅ Dailymotion、Bilibili 以及更多平台！

[查看完整列表 →](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
</details>

<details>
<summary><b>🎵 可以只從影片中擷取音訊嗎？</b></summary>

可以！Seal Plus 提供出色的音訊擷取功能：
- 開啟「儲存為音訊」選項
- 選擇格式（MP3、M4A、OPUS 等）
- 自動嵌入中繼資料
- 包含專輯封面/縮圖
- 可自訂品質設定

非常適合下載音樂與 Podcast！
</details>

<details>
<summary><b>🔧 General 與 Custom Command 模式有什麼差別？</b></summary>

**General Mode**（簡易）：
- 使用者友善的介面
- 預先設定的選項
- 自動整理檔案
- 適合大多數使用者

**Custom Command Mode**（進階）：
- 完整的 yt-dlp CLI 存取權限
- 建立並儲存範本
- 進階設定
- 類似終端機的控制方式

根據你的使用習慣選擇適合自己的模式！
</details>

<details>
<summary><b>🔐 Seal Plus 安全嗎？它會收集我的資料嗎？</b></summary>

**絕對安全！**
- ✅ 100% 開放原始碼（可查看所有程式碼）
- ✅ 不收集資料或分析資訊
- ✅ 沒有廣告或追蹤器
- ✅ 除下載功能外不需要網際網路權限
- ✅ 所有處理均在你的裝置本機完成
- ✅ 採用 GPL-3.0 授權

你可以在[原始碼](https://github.com/MaheshTechnicals/Sealplus)中自行驗證。
</details>

<details>
<summary><b>📱 Seal 和 Seal Plus 有什麼差別？</b></summary>

**Seal Plus** 是一個強化版分支，具有：
- 🎨 **獨家漸層深色主題**，搭配玻璃擬態效果
- 🚀 **自動更新系統**，預設啟用
- 📺 **強化社群**（YouTube、Telegram）
- 🔧 **額外 UI 改進**與最佳化
- 🎯 **由 Mahesh Technicals 積極維護**
- 🏆 **最新技術堆疊**（Kotlin 2.0、Compose 2025、SDK 36）

兩者皆為免費且開放原始碼！
</details>

<details>
<summary><b>❌ 我遇到了下載錯誤，該怎麼辦？</b></summary>

可以嘗試以下解決方法：
1. **更新 yt-dlp**：設定 → 關於 → 更新 yt-dlp
2. **檢查網路**：確保網路連線穩定
3. **清除快取**：設定 → 儲存空間 → 清除快取
4. **嘗試自訂指令**：某些網站需要特定參數
5. **檢查網站支援情況**：造訪[支援的網站列表](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
6. **回報問題**：在 [GitHub Issues](https://github.com/MaheshTechnicals/Sealplus/issues) 中提供詳細資訊

大多數問題都可以透過更新 yt-dlp 解決！
</details>
