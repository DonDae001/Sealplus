## ✨ Əsas xüsusiyyətlər

### 🎨 Premium interfeys və mövzular

- **Gradient Dark Theme**
  - ⭐ *Yalnız Seal Plus üçün* — OLED üçün uyğun tünd fonlar, canlı gradientlər, glassmorphism və hamar animasiyalar.
- **Material Design 3** — Dinamik rənglər, Tünd/Açıq mövzular və müasir Compose komponentləri.

### 🎯 Əsas yükləmə imkanları

- **Universal Yükləyici** — [yt-dlp](https://github.com/yt-dlp/yt-dlp) vasitəsilə 1000-dən çox platformanı dəstəkləyir.
- **Yüksək keyfiyyətli audio çıxarışı** — [mutagen](https://github.com/quodlibet/mutagen) vasitəsilə metadata və miniatür şəkil əlavə etməklə MP3, M4A, OPUS, FLAC və ya WAV formatlarında audio çıxarın.
- **Pleylist dəstəyi** — Tərəqqi izləmə, fərdiləşdirilə bilən adlandırma və davam etdirmə dəstəyi ilə bütün pleylistləri yükləyin.
- **Altyazı dəstəyi** — Altyazıları videolara əlavə edin və ya çoxdilli dəstəklə ayrıca yükləyin.

### ⚡ Təkmil xüsusiyyətlər

- **Yüksək sürətli yükləmələr** — Çoxsaylı bağlantılar, avtomatik yenidən cəhd və davam etdirmə dəstəyi ilə inteqrasiya edilmiş [aria2c](https://github.com/aria2/aria2) mühərriki.
- **Fərdi əmrlər** — Tam CLI funksionallığı ilə fərdi yt-dlp əmr şablonları yaradın və yadda saxlayın.
- **Yükləmə meneceri** — Yükləmə tarixçəsini izləyin, yükləmələri axtarın və filtrləyin, faylları paylaşın və toplu əməliyyatlar həyata keçirin.

### 🚀 Yalnız Seal Plus-a məxsus xüsusiyyətlər

- **Avtomatik yeniləmə sistemi** — Avtomatik versiya yoxlaması, dəyişikliklər jurnalının göstərilməsi və bir kliklə APK yeniləmələri.
- **Təkmilləşdirilmiş icma** — [YouTube dərslərinə](https://youtube.com/@maheshtechnicals) və [Telegram icmasına](https://t.me/maheshtechnicals) çıxış, müntəzəm yeniləmələr və dəstək.

### 💻 Texniki üstünlüklər

- **Saf Kotlin arxitekturası** — Tək Activity, 100% Jetpack Compose interfeysi, Clean MVVM və Kotlin Coroutines.
- **Müasir texnologiya dəsti** — Android SDK 37, Kotlin 2.3.21, Jetpack Compose BOM 2026.05.01, Room 2.8.4 və Material 3.
- **Optimallaşdırılmış performans** — Aparat sürətləndirməli animasiyalar, səmərəli yaddaş idarəetməsi və batareya sərfiyyatını nəzərə alan fon emalı.

### 📱 Cihaz uyğunluğu

| Tələb | Spesifikasiya |
|------------|---------------|
| **Minimum Android** | Android 7.0 (API 24) |
| **Hədəf Android** | Android 17 (API 37) |
| **Cari versiya** | 3.0.0 |
| **Buraxılış tarixi** | 30 iyul 2026 |

### 📋 Quraşdırma təlimatları

1. **Yükləyin** — Cihazınızın arxitekturasına uyğun APK-nı [Releases](https://github.com/MaheshTechnicals/Sealplus/releases/latest) səhifəsindən yükləyin.
2. **Aktivləşdirin** — Parametrlər → Təhlükəsizlik bölməsindən "Naməlum mənbələrdən quraşdırma" seçimini aktivləşdirin.
3. **Açın** — Yüklənmiş APK faylını açın.
4. **İzləyin** — Ekrandakı quraşdırma təlimatlarını izləyin.
5. **İcazə verin** — Tətbiqi başladarkən tələb olunan icazələri verin.
6. **Zövq alın** — Problemsiz yükləmələrdən istifadə edin!

> [!TIP]
> **Avtomatik yeniləmə funksiyası**: Quraşdırıldıqdan sonra Seal Plus avtomatik olaraq yeniləmələri yoxlayacaq. Yeni versiyalar mövcud olduqda sizə bildiriş göndəriləcək və bir kliklə yeniləyə biləcəksiniz!

> [!WARNING]
> **Təhlükəsizlik bildirişi**: Seal Plus-u həmişə yalnız [rəsmi GitHub releases səhifəmizdən](https://github.com/MaheshTechnicals/Sealplus/releases) yükləyin. Orijinal və təhlükəsiz versiyanı əldə etdiyinizə əmin olmaq üçün üçüncü tərəf mənbələrindən yükləməyin.

## ❓ Tez-tez verilən suallar

<details>
<summary><b>📱 Gradient Dark mövzusunu necə aktivləşdirə bilərəm?</b></summary>

1. **Parametrləri** açın
2. **Görünüş və hiss** bölməsinə keçin
3. **Tünd mövzu**nu aktivləşdirin (əgər artıq aktiv deyilsə)
4. **Gradient Dark** keçidini aktivləşdirin
5. Premium glassmorphism interfeysindən zövq alın!

Bu mövzu tünd fonlar, canlı mavi-bənövşəyi gradientlər və hamar animasiyalar təqdim edir.
</details>

<details>
<summary><b>🔄 Avtomatik yeniləmə necə işləyir?</b></summary>

Seal Plus GitHub releases bölməsindən yeniləmələri avtomatik yoxlayır:

- Bütün quraşdırmalar üçün standart olaraq aktivdir
- Tətbiqi açdığınız zaman yoxlayır (narahatedici deyil)
- Yeniləmədən əvvəl dəyişikliklər jurnalını göstərir
- Bir kliklə yükləmə və quraşdırma
- Parametrlər → Haqqında → Avtomatik yeniləmə bölməsindən deaktiv edilə bilər

Artıq yeniləmələri əl ilə yoxlamağa ehtiyac yoxdur!
</details>

<details>
<summary><b>📥 Hansı arxitekturanı yükləməliyəm?</b></summary>

| Arxitektura | Tövsiyə olunur |
|--------------|-----------------|
| **arm64-v8a** | Əksər müasir Android telefonları (2017+) - **Tövsiyə olunur** |
| **armeabi-v7a** | Köhnə telefonlar (2011-2017) |
| **x86_64** | Intel/AMD əsaslı cihazlar, emulyatorlar |
| **x86** | Köhnə Intel/AMD cihazları |
| **universal** | Bütün cihazlarda işləyir (daha böyük fayl ölçüsü) |

Bu layihə BrowserStack ilə sınaqdan keçirilib.

**Əmin deyilsiniz?** **universal** APK-nı yükləyin — bütün cihazlarda işləyir!
</details>

<details>
<summary><b>🎵 Videolardan yalnız audio çıxara bilərəm?</b></summary>

Bəli! Seal Plus yüksək keyfiyyətli audio çıxarışı təqdim edir:

- "Audio kimi saxla" seçimini aktivləşdirin
- Formatı seçin (MP3, M4A, OPUS və s.)
- Metadata avtomatik əlavə olunur
- Albom üz qabığı/miniatür şəkil əlavə olunur
- Keyfiyyət parametrləri fərdiləşdirilə bilər

Musiqi yükləmələri və podkastlar üçün idealdır!
</details>

<details>
<summary><b>🔧 General və Custom Command rejimləri arasındakı fərq nədir?</b></summary>

**General Mode** (Asan):
- İstifadəsi asan interfeys
- Əvvəlcədən konfiqurasiya edilmiş seçimlər
- Avtomatik fayl təşkili
- Əksər istifadəçilər üçün uyğundur

**Custom Command Mode** (Təkmil):
- yt-dlp CLI-yə tam giriş
- Şablonlar yaradın və yadda saxlayın
- Təkmil konfiqurasiyalar
- Terminala bənzər idarəetmə

Rahatlıq səviyyənizə uyğun rejimi seçin!
</details>

<details>
<summary><b>🔐 Seal Plus təhlükəsizdirmi? Məlumatlarımı toplayır?</b></summary>

**Tamamilə təhlükəsizdir!**

- ✅ 100% açıq mənbəlidir (bütün koda baxa bilərsiniz)
- ✅ Məlumat toplanması və analitika yoxdur
- ✅ Reklam və izləyicilər yoxdur
- ✅ Yükləmələr istisna olmaqla internet icazəsi tələb etmir
- ✅ Bütün emal cihazınızda lokal şəkildə həyata keçirilir

</details>

<details>
<summary><b>❌ Yükləmə xətaları alıram. Nə etməliyəm?</b></summary>

Bu həlləri sınayın:

1. **yt-dlp-ni yeniləyin**: Parametrlər → Haqqında → yt-dlp-ni yenilə
2. **İnterneti yoxlayın**: Bağlantının sabit olduğundan əmin olun
3. **Keşi təmizləyin**: Parametrlər → Yaddaş → Keşi təmizlə
4. **Fərdi əmri sınayın**: Bəzi saytlar xüsusi parametrlər tələb edir
5. **Sayt dəstəyini yoxlayın**: [dəstəklənən saytlar siyahısına](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) baxın
6. **Problemi bildirin**: Detallarla birlikdə [GitHub Issues](https://github.com/MaheshTechnicals/Sealplus/issues) bölməsindən istifadə edin

Əksər problemlər yt-dlp-ni yeniləməklə həll olunur!
</details>
