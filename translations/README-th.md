## ✨ ฟีเจอร์หลัก

### 🎨 UI และธีมระดับพรีเมียม
- **ธีม Gradient Dark**
  - ⭐ *เฉพาะสำหรับ Seal Plus* — พื้นหลังสีเข้มที่เหมาะกับ OLED, ไล่เฉดสีสดใส, glassmorphism และแอนิเมชันที่ลื่นไหล
- **Material Design 3** — สีแบบไดนามิก ธีมสว่าง/มืด และคอมโพเนนต์ Compose ที่ทันสมัย

### 🎯 ฟีเจอร์การดาวน์โหลดหลัก
- **ตัวดาวน์โหลดอเนกประสงค์** — รองรับมากกว่า 1,000 แพลตฟอร์มผ่าน [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- **การแยกเสียงคุณภาพสูง** — แยกเสียงเป็น MP3, M4A, OPUS, FLAC หรือ WAV พร้อมข้อมูลเมตาและภาพปกผ่าน [mutagen](https://github.com/quodlibet/mutagen)
- **รองรับเพลย์ลิสต์** — ดาวน์โหลดเพลย์ลิสต์ทั้งหมดพร้อมติดตามความคืบหน้า ตั้งชื่อไฟล์เอง และรองรับการดาวน์โหลดต่อ
- **รองรับคำบรรยาย** — ฝังคำบรรยายในวิดีโอหรือดาวน์โหลดแยก พร้อมรองรับหลายภาษา

### ⚡ ฟีเจอร์ขั้นสูง
- **ดาวน์โหลดความเร็วสูง** — ใช้เอนจิน [aria2c](https://github.com/aria2/aria2) ในตัว พร้อมการเชื่อมต่อหลายช่องทาง การลองใหม่อัตโนมัติ และการดาวน์โหลดต่อ
- **คำสั่งที่กำหนดเอง** — สร้างและบันทึกเทมเพลตคำสั่ง yt-dlp พร้อมฟังก์ชัน CLI แบบเต็มรูปแบบ
- **ตัวจัดการการดาวน์โหลด** — ดูประวัติการดาวน์โหลด ค้นหาและกรองรายการ แชร์ไฟล์ และดำเนินการหลายรายการพร้อมกัน

### 🚀 ฟีเจอร์เฉพาะของ Seal Plus
- **ระบบอัปเดตอัตโนมัติ** — ตรวจสอบเวอร์ชันโดยอัตโนมัติ แสดง changelog และอัปเดต APK ได้ในคลิกเดียว
- **ชุมชนที่ได้รับการปรับปรุง** — เข้าถึง [บทเรียนบน YouTube](https://youtube.com/@maheshtechnicals) และ [ชุมชน Telegram](https://t.me/maheshtechnicals) พร้อมการอัปเดตและการสนับสนุนอย่างสม่ำเสมอ

### 💻 เทคโนโลยีที่มีประสิทธิภาพ
- **สถาปัตยกรรม Kotlin ล้วน** — ใช้ Activity เดียว, UI 100% ด้วย Jetpack Compose, Clean MVVM และ Kotlin Coroutines
- **เทคโนโลยีสมัยใหม่** — Android SDK 37, Kotlin 2.3.21, Jetpack Compose BOM 2026.05.01, Room 2.8.4 และ Material 3
- **ประสิทธิภาพที่ได้รับการปรับปรุง** — แอนิเมชันเร่งด้วยฮาร์ดแวร์ การจัดการหน่วยความจำอย่างมีประสิทธิภาพ และการประมวลผลเบื้องหลังที่คำนึงถึงแบตเตอรี่

<i>สำหรับอุปกรณ์ Android ส่วนใหญ่ ให้ติดตั้งเวอร์ชัน **arm64-v8a** เพื่อประสิทธิภาพที่ดีที่สุด</i>

### 📱 ความเข้ากันได้ของอุปกรณ์

| ข้อกำหนด | รายละเอียด |
|------------|---------------|
| **Android ขั้นต่ำ** | Android 7.0 (API 24) |
| **Android เป้าหมาย** | Android 17 (API 37) |
| **เวอร์ชันปัจจุบัน** | 3.0.0 |
| **วันที่เผยแพร่** | 30 กรกฎาคม 2026 |

### 📋 ขั้นตอนการติดตั้ง

1. **ดาวน์โหลด** APK ที่เหมาะกับสถาปัตยกรรมของอุปกรณ์จาก [Releases](https://github.com/MaheshTechnicals/Sealplus/releases/latest)
2. **เปิดใช้งาน** "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" ใน การตั้งค่า → ความปลอดภัย
3. **เปิด** ไฟล์ APK ที่ดาวน์โหลดมา
4. **ทำตาม** ขั้นตอนการติดตั้ง
5. **อนุญาต** สิทธิ์ที่จำเป็นเมื่อเปิดแอป
6. **เพลิดเพลิน** กับการดาวน์โหลดที่ง่ายดาย!

> [!TIP]
> **ฟีเจอร์อัปเดตอัตโนมัติ**: หลังติดตั้ง Seal Plus จะตรวจสอบการอัปเดตโดยอัตโนมัติ คุณจะได้รับการแจ้งเตือนเมื่อมีเวอร์ชันใหม่ และสามารถอัปเดตได้ในคลิกเดียว!

> [!WARNING]
> **คำเตือนด้านความปลอดภัย**: ดาวน์โหลด Seal Plus จาก [หน้า GitHub Releases อย่างเป็นทางการ](https://github.com/MaheshTechnicals/Sealplus/releases) เท่านั้น อย่าดาวน์โหลดจากแหล่งภายนอก เพื่อให้มั่นใจว่าได้รับเวอร์ชันที่แท้จริงและปลอดภัย

4. เปิดตัวเลือก **Gradient Dark**
5. เพลิดเพลินกับ UI ระดับพรีเมียมพร้อม glassmorphism!

ธีมนี้ใช้พื้นหลังสีเข้มพร้อมการไล่เฉดสีฟ้าและม่วงที่สดใส รวมถึงแอนิเมชันที่ลื่นไหล

- ดาวน์โหลดและติดตั้งได้ในคลิกเดียว
- สามารถปิดได้ที่ การตั้งค่า → เกี่ยวกับ → อัปเดตอัตโนมัติ

<details>
<summary><b>🔧 โหมด General และ Custom Command แตกต่างกันอย่างไร?</b></summary>

**โหมด General** (ใช้งานง่าย):
- อินเทอร์เฟซใช้งานง่าย
- ตัวเลือกที่ตั้งค่าไว้ล่วงหน้า
- จัดระเบียบไฟล์โดยอัตโนมัติ
- เหมาะสำหรับผู้ใช้ส่วนใหญ่

**โหมด Custom Command** (ขั้นสูง):
- เข้าถึง yt-dlp CLI ได้อย่างเต็มรูปแบบ
- สร้างและบันทึกเทมเพลต
- การตั้งค่าขั้นสูง
- ควบคุมในรูปแบบคล้ายเทอร์มินัล

เลือกโหมดตามระดับความคุ้นเคยของคุณ!
</details>

ทั้งสองแอปฟรีและเป็นโอเพนซอร์ส!

<details>
<summary><b>❌ ฉันพบข้อผิดพลาดในการดาวน์โหลด ควรทำอย่างไร?</b></summary>

ลองใช้วิธีแก้ไขต่อไปนี้:
1. **อัปเดต yt-dlp**: การตั้งค่า → เกี่ยวกับ → อัปเดต yt-dlp
2. **ตรวจสอบอินเทอร์เน็ต**: ตรวจสอบให้แน่ใจว่าการเชื่อมต่อมีความเสถียร
3. **ล้างแคช**: การตั้งค่า → พื้นที่จัดเก็บ → ล้างแคช
4. **ลองใช้คำสั่งที่กำหนดเอง**: บางเว็บไซต์ต้องใช้พารามิเตอร์เฉพาะ
5. **ตรวจสอบการรองรับเว็บไซต์**: ดู [รายการเว็บไซต์ที่รองรับ](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
6. **รายงานปัญหา**: เปิด [GitHub Issue](https://github.com/MaheshTechnicals/Sealplus/issues) พร้อมรายละเอียด

ปัญหาส่วนใหญ่แก้ไขได้ด้วยการอัปเดต yt-dlp!
