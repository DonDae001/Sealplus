## ✨ 主要功能

### 🎨 高级 UI 与主题
- **渐变深色主题**
  - ⭐ *Seal Plus 独家功能* — OLED 友好的深色背景、鲜艳渐变、毛玻璃效果以及流畅动画。
- **Material Design 3** — 动态配色、深色/浅色主题以及现代化 Compose 组件。

### 🎯 核心下载功能
- **通用下载器** — 通过 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 支持 1000+ 个平台。
- **高质量音频提取** — 提取 MP3、M4A、OPUS、FLAC 或 WAV，并通过 [mutagen](https://github.com/quodlibet/mutagen) 嵌入元数据和缩略图。
- **播放列表支持** — 下载完整播放列表，支持进度跟踪、自定义命名以及断点续传。
- **字幕支持** — 将字幕嵌入视频，或单独下载字幕，并支持多种语言。

### ⚡ 高级功能
- **高速下载** — 内置 [aria2c](https://github.com/aria2/aria2) 引擎，支持多连接下载、自动重试和断点续传。
- **自定义命令** — 创建并保存自定义 yt-dlp 命令模板，支持完整 CLI 功能。
- **下载管理器** — 查看下载历史、搜索和筛选下载内容、分享文件以及执行批量操作。

### 🚀 Seal Plus 独家功能
- **自动更新系统** — 自动检查版本、显示更新日志，并支持一键更新 APK。
- **增强社区** — 访问 [YouTube 教程](https://youtube.com/@maheshtechnicals) 和 [Telegram 社区](https://t.me/maheshtechnicals)，获取定期更新与支持。

### 💻 技术优势
- **纯 Kotlin 架构** — 单 Activity、100% Jetpack Compose UI、Clean MVVM 和 Kotlin Coroutines。
- **现代技术栈** — Android SDK 37、Kotlin 2.3.21、Jetpack Compose BOM 2026.05.01、Room 2.8.4 和 Material 3。
- **性能优化** — 硬件加速动画、高效内存管理以及注重电量消耗的后台处理。

## ⬇️ 下载与安装
<div align="center">
<img src="https://github.com/nyxiereal/get-it-on/blob/master/badges/png/github.png" width=258 height=100>

### 📱 设备兼容性

| 要求 | 规格 |
|------------|---------------|
| **最低 Android 版本** | Android 7.0 (API 24) |
| **目标 Android 版本** | Android 17 (API 37) |
| **当前版本** | 3.0.0 |
| **发布日期** | 2026 年 7 月 30 日 |

### 📋 安装说明

1. 从 [Releases](https://github.com/MaheshTechnicals/Sealplus/releases/latest) 下载适合设备架构的 APK
2. 在设置 → 安全中启用“允许从未知来源安装”
3. 打开下载的 APK 文件
4. 按照安装提示操作
5. 启动应用时授予必要的权限
6. **享受**流畅的下载体验！

> [!TIP]
> **自动更新功能**：安装后，Seal Plus 会自动检查更新。有新版本时，你会收到通知，并可以一键完成更新！

> [!WARNING]
> **安全提示**：请始终仅从我们的[官方 GitHub Releases 页面](https://github.com/MaheshTechnicals/Sealplus/releases)下载 Seal Plus。请勿从第三方来源下载，以确保获得正版且安全的版本。

## ❓ 常见问题

<details>
<summary><b>📱 如何启用渐变深色主题？</b></summary>

1. 打开**设置**
2. 进入**外观与体验**
3. 启用**深色主题**（如果尚未启用）
4. 打开**Gradient Dark**开关
5. 享受高级毛玻璃 UI！

该主题采用深色背景，并搭配鲜艳的蓝紫色渐变和流畅动画。
</details>

<details>
<summary><b>🔄 自动更新如何工作？</b></summary>

Seal Plus 会自动从 GitHub Releases 检查更新：
- 默认对所有安装启用
- 打开应用时检查（不会造成打扰）
- 更新前显示更新日志
- 一键下载并安装
- 可在设置 → 关于 → 自动更新中禁用

无需再手动检查更新！
</details>

<details>
<summary><b>📥 我应该下载哪个架构？</b></summary>

| 架构 | 推荐设备 |
|--------------|-----------------|
| **arm64-v8a** | 大多数现代 Android 手机（2017 年及以后）— **推荐** |
| **armeabi-v7a** | 较旧的手机（2011–2017 年） |
| **x86_64** | 基于 Intel/AMD 的设备、模拟器 |
| **x86** | 较旧的 Intel/AMD 设备 |
| **universal** | 适用于所有设备（文件更大） |

本项目已通过 BrowserStack 测试。

**不知道该选哪个？** 下载 **universal** APK — 它适用于所有设备！
</details>

<details>
<summary><b>🌍 可以使用它从任何网站下载吗？</b></summary>

Seal Plus 通过 yt-dlp 支持 **1000+ 个平台**，包括：
- ✅ YouTube、YouTube Music
- ✅ Instagram、TikTok、Twitter/X
- ✅ Facebook、Reddit、Vimeo
- ✅ Twitch、SoundCloud、Bandcamp
- ✅ Dailymotion、Bilibili 以及更多平台！

[查看完整列表 →](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
</details>

<details>
<summary><b>🎵 可以只从视频中提取音频吗？</b></summary>

可以！Seal Plus 提供出色的音频提取功能：
- 打开“保存为音频”选项
- 选择格式（MP3、M4A、OPUS 等）
- 自动嵌入元数据
- 包含专辑封面/缩略图
- 可自定义质量设置

非常适合下载音乐和播客！
</details>

<details>
<summary><b>🔧 General 和 Custom Command 模式有什么区别？</b></summary>

**General Mode**（简单）：
- 用户友好的界面
- 预配置选项
- 自动整理文件
- 适合大多数用户

**Custom Command Mode**（高级）：
- 完整的 yt-dlp CLI 访问权限
- 创建并保存模板
- 高级配置
- 类似终端的控制方式

根据你的使用习惯选择适合自己的模式！
</details>

<details>
<summary><b>🔐 Seal Plus 安全吗？它会收集我的数据吗？</b></summary>

**绝对安全！**
- ✅ 100% 开源（可以查看全部代码）
- ✅ 不收集数据或分析信息
- ✅ 没有广告或追踪器
- ✅ 除下载功能外不需要互联网权限
- ✅ 所有处理均在你的设备本地完成
- ✅ 使用 GPL-3.0 许可证

你可以在[源代码](https://github.com/MaheshTechnicals/Sealplus)中自行验证。
</details>

<details>
<summary><b>📱 Seal 和 Seal Plus 有什么区别？</b></summary>

**Seal Plus** 是一个增强版分支，拥有：
- 🎨 **独家渐变深色主题**，带有毛玻璃效果
- 🚀 **自动更新系统**，默认启用
- 📺 **增强社区**（YouTube、Telegram）
- 🔧 **额外 UI 改进**和优化
- 🎯 **由 Mahesh Technicals 积极维护**
- 🏆 **最新技术栈**（Kotlin 2.0、Compose 2025、SDK 36）

两者都是免费且开源的！
</details>

<details>
<summary><b>❌ 我遇到了下载错误，该怎么办？</b></summary>

可以尝试以下解决方法：
1. **更新 yt-dlp**：设置 → 关于 → 更新 yt-dlp
2. **检查网络**：确保网络连接稳定
3. **清除缓存**：设置 → 存储 → 清除缓存
4. **尝试自定义命令**：某些网站需要特定参数
5. **检查网站支持情况**：访问[支持的网站列表](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
6. **报告问题**：在 [GitHub Issues](https://github.com/MaheshTechnicals/Sealplus/issues) 中提供详细信息

大多数问题都可以通过更新 yt-dlp 解决！
</details>
